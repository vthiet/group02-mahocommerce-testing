# Test Specification Details: Product & Catalog Management (Maho Commerce)

**Project:** Maho Commerce Automation Testing  
**Environment:** Localhost / DDEV (Maho Commerce 26.9.3 with Sample Data)  
**Execution Tool:** Playwright (TypeScript/JavaScript)  

## Automation Environment Preconditions

- The local Maho 26.9.3 DDEV site is installed, running, reachable from Playwright, and has sample data installed. Set `MAHO_BASE_URL` to its storefront URL.
- Use a disposable local test database, not a production catalog. Configure an admin account with category and product permissions; store its credentials only in ignored local environment configuration. Set `MAHO_ADMIN_PATH` to the actual admin route prefix.
- Generate one unique `${runId}` per suite run (timestamp plus random suffix is recommended). Reuse it for dependent data names and SKUs; it is a placeholder, not literal UI text.
- Prepare the stated category, product, image, and configurable-attribute fixtures before each case. Dependent cases must either run in order or independently create/restore their prerequisites. Clean up test records after the suite, including after failures.
- Confirm environment-dependent behavior before asserting it: store view/grid columns and filters, website assignment, currency/tax, category URL suffix, out-of-stock display, search indexing, configurable swatches, and add-to-cart redirect.
- Configure any needed local reindex/cache refresh in test setup. Keep settings used for conditional expectations in test configuration.
