# Test Specification Details: Promotion Management (Maho Commerce)

**Project:** Maho Commerce Automation Testing  
**Environment:** Localhost / DDEV (Maho Commerce 26.9.3 with Sample Data)  
**Execution Tool:** Playwright (TypeScript/JavaScript)  

**Shared local test setup:** Use a disposable local DDEV database and an admin account configured in `playwright-automation/.env`. Each test must create or verify its own fixture records with unique names/codes, use a fresh storefront context/cart where applicable, and clean up created rules, coupons, products, and categories afterward. Use the store's configured currency and tax/shipping settings in total assertions. For catalog-rule price tests, use enabled, visible, in-stock simple products assigned to the target website and customer group, with no special price and no other applicable catalog rules. For cart-rule tests, explicitly configure website, customer group, dates, coupon mode, conditions, and action. Do not depend on unspecified sample-data IDs or existing rules.
