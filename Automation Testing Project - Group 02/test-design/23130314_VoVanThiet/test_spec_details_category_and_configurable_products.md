# Test Specification Details: Category & Configurable Product Catalog

**Project:** MahoCommerce Automation Testing  
**Environment:** Local MahoCommerce source in `maho/` (26.9.3)  
**Execution Tool:** Playwright Test / TypeScript  
**Design matrix:** [`test_design_category_and_configurable_products.md`](test_design_category_and_configurable_products.md)

## Automation Preconditions

- Run against a disposable local Maho database with storefront and Admin reachable. Use a least-privilege Admin account with Catalog permissions; credentials belong in ignored local environment configuration.
- Generate a unique `${runId}` for category names, product names and SKUs. Create only the attributes, categories, products, images, and associations needed by a case; clean them up even after failure.
- Configurable cases require global dropdown attributes enabled for configurable products, a compatible attribute set, and simple variants with explicit website, visibility, status, stock, and image settings.
- Determine store-view URL suffix, index/cache refresh needs, swatch settings, currency and stock display from the local installation. Do not hardcode sample IDs or theme wording.
- These cases intentionally omit general product CRUD/grid/filter/search coverage assigned elsewhere.
