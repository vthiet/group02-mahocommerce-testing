# Test Specification Details: Shopping Cart & Order Placement (Maho Commerce)

**Project:** Maho Commerce Automation Testing  
**Environment:** Localhost (Maho Commerce with Seeded Sample Data)  
**Execution Tool:** Playwright (TypeScript/JavaScript)  

**Local test environment preconditions:** Use a dedicated local Maho installation and test database. Seed fixture products/customer, enable the configuration described by each case, and reset cart/customer/order state before runs. `PW-SIMPLE-50` must be visible and purchasable, cost `$50.00`, have stock `10`, minimum sale quantity `1`, and backorders disabled. Use a physical product for shipping cases. Verify theme-specific controls and methods during setup; fail setup clearly if absent. Capture generated order IDs dynamically.
