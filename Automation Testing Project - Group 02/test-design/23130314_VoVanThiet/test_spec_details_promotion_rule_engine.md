# Test Specification Details: Promotion Rule Engine

**Project:** MahoCommerce Automation Testing  
**Environment:** Local MahoCommerce source in `maho/` (26.9.3)  
**Execution Tool:** Playwright Test / TypeScript  
**Design matrix:** [`test_design_promotion_rule_engine.md`](test_design_promotion_rule_engine.md)

## Automation Preconditions

- Use a disposable local database, Admin user with Promotions permissions, and storefront reachable by Playwright. Create a new `${runId}` for every rule, coupon-free automatic promotion, and fixture product.
- Explicitly configure status, website, customer group, dates, conditions, action, priority and coupon mode. This feature tests rule evaluation; coupon CRUD and storefront coupon entry are out of scope.
- Catalog-price fixtures must be enabled, visible, in stock, assigned to the tested website, with no special price or competing rule unless the case calls for competition.
- Automatic cart-rule fixtures use fresh carts and products with known price/tax/shipping settings. Reindex/cache refresh through supported local setup where required.
- Priority, stop/discard, tax, and free-shipping semantics must be confirmed against this Maho build before exact expected amounts are locked. Store currency/timezone are test configuration.
